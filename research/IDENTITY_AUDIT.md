# 人物身份核对与张旭记录修正

2026-10-06 修复：百科返回的标题与姓名相同，只能证明文字一致，不能证明是目标人物。旧审计把 1961 年出生的神经科学家张旭与唐代书法家张旭混合，又从旧知识文本补入书帖名称，使错误人物看起来像正确结果。

## 发布条件

`baidu_knowledge_audit.py` 维护独立的目标人物时代和宽出生年份范围。范围用于排除同名人物，不声称争议生卒年已获定论，也不从本次 API 响应或待更新知识文本反向生成。已知歧义较高的张旭、王羲之、颜真卿、刘墉还须有对应的字、号或通称。

只有以下条件全部满足，结果才是 `identity_verified`：

- 词条标题与目标姓名精确一致。异体字、别名跳转及消歧标题保留人工复核状态。
- 职业或人物介绍明确指出书法家、书画家身份；作品名或旧文本不构成人物身份依据。
- `所处时代` 或主体开头的出生年份可与目标时代核对。显式时代、出生年份如有冲突，优先拒绝；纯年份、ISO 日期与带“年”的日期都核对。
- 为该目标设置的额外身份标识得到核对。

缺少目标档案或证据时为 `needs_manual_review`；时代冲突为 `identity_mismatch`。这些状态不生成 `verified_text`、不下载作品图片、不覆盖现有知识。`write_data()` 重新检查原始身份字段，旧 `status=exact` 或只有“已核验”标签的记录无法直接发布。原有的逐项合并、失败保留原记录、临时文件加原子替换仍保留。

这只是人物消歧检查，并不替代每条生平、作品真伪、作者归属、图片使用条件的人工核验。审计缺乏足够的书法身份描述时，宁可留待核对，也不以同名或“研究唐代书法”推断人物身份。

## 张旭修正的公开来源

- [故宫博物院《张旭》](https://www.dpm.org.cn/lemmas/241546.html)：其公开检索内容记有字伯高、苏州人、金吾长史、楷法与草书，以及《肚痛帖》《古诗四帖》等传世书迹。该站本次直接访问超时，公开检索内容可读。
- [国立故宫博物院《元鲜于枢论张旭怀素高闲草书》](https://digitalarchive.npm.gov.tw/opendata/Pub/Detail/636?dep=P&mode=full)：馆藏说明明确讨论唐代张旭、怀素、高闲的草书，支持时代与书法身份的交叉核对。馆藏作者是鲜于枢，不能将这件作品误记为张旭本人所书。
- [教育部《重编国语辞典修订本》“张旭”](https://dict.revised.moe.edu.tw/dictView.jsp?ID=117003&la=0&powerMode=0)：确认字伯高、唐代吴地人物及草书身份，并注明生卒年不详。与故宫人物条的具体年数不同，因此修正记录不选定确切生卒年。

知识文本仅保留上述来源支持的保守表述，传世书迹不等同于所有现存版本已确认真迹。文字为事实摘要；国立故宫博物院相关馆藏说明的署名来源为“元赵孟頫鲜于枢墨迹合册　册　元鲜于枢论张旭怀素高闲草书，国立故宫博物院，台北，CC BY 4.0 @ www.npm.gov.tw”。

## 已保存审计的处置

对仓库保存的 53 条 API 快照进行了离线身份重分类，没有重新抓取百科、下载图片或运行批量审计。可见的明确同名错采是张旭。其原始科研人员字段仍留作拒绝证据，错误 `verified_text` 改存 `rejected_text`，原图片移到 `unverified_images`，供界面消费的 `images` 清空。正确文字与依据记在独立 `manual_correction`，不把被拒绝的百科条目标成已核验。

其余记录按同一规则标记：38 条身份符合约束，14 条仍需人工检查（包括别名跳转或缺少明确书法身份），1 条身份冲突。未因此判定所有待检查记录都有错误，也未更改这些人物的知识文本。`research/knowledge_audit.json` 的另一批结果本就标记 `needs_manual_review`，没有把它们提升为已核验。

本次未改已有 Chroma 数据库。已建立的索引不会自动应用知识源文件修正；需由数据库所有者按原有流程重新建库后才会更新检索内容。
